# DS II - Agenda 04
## Controle de Estoque de TI

Exemplo simples em PHP desenvolvido para demonstrar o uso de **funções** e **estruturas de repetição**.

### Objetivo
Exibir uma pequena relação de equipamentos de TI e calcular informações do estoque.

### Conceitos aplicados
- Função `situacaoEstoque()`: identifica se o estoque está normal, em atenção ou baixo.
- Função `valorTotalItem()`: calcula o valor total de cada item em estoque.
- Função `resumoEstoque()`: calcula totais gerais.
- Estrutura `foreach`: percorre o array de equipamentos para realizar os cálculos e montar a tabela.

### Como executar no XAMPP
1. Copie a pasta do projeto para `C:\xampp\htdocs\`.
2. Inicie o Apache no XAMPP.
3. Acesse no navegador:
   `http://localhost/ds2-agenda04-controle-estoque-ti/`
